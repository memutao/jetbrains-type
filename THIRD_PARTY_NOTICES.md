## Design references

The New UI Dark workbench palette and the optional UI settings were designed after reviewing the top JetBrains UI extensions. No source code or image assets were copied from these projects; only general design ideas (surface colors, accent placement, font/UI setting choices) were used.

- **EdwinSulaiman/jetbrains-rider-dark-theme** — MIT — New UI surface palette (`#1E1F22`, `#2B2D30`, `#3474F0`).
- **MichaelZhou/fleet-theme** — MIT — modern workbench color coverage, inlay hint guidance, semantic-token breadth.
- **nicohlr/pycharm** — MIT — multiple-theme entry point and contrast choices.
- **NarasimaPandiyan/jetbrainsmono** — GPL-3.0 — activation/deactivation UX and font settings only; the bundled GPL fonts/code were **not** copied.
- **rokoroku/vscode-theme-darcula**, **Anan/jetbrains-darcula-theme**, **csantiago132/intellij-ish-darcula-theme** — MIT — classic Darcula palette and readability checks.
- **Mostik/JetBrainsIcons** — no explicit license — Java/Maven/Gradle mapping ideas only; no assets copied.

The full ranking and comparison are in `docs/UI_PLUGIN_RESEARCH.md`.
